# Vessel Maintenance Reference 1.0 🛥️

A lightweight, digital reference dashboard designed specifically for inland waterway towboat engineers. This utility provides clear troubleshooting workflows and technical data right in your browser.

## 📱 Live Application Access
You can open and run this application instantly on any laptop, tablet, or smartphone by visiting the live deployment link:
👉 https://d3v6174.github.io/Vessel-Maintenance-Reference-1.0/

> ⚠️ **Note on Connection:** This reference tool currently requires an active internet connection or cellular signal to load and function properly. 

## ⚓ Features & Layout
* **High-Visibility Dark Mode:** Designed specifically for midnight watches, dim environments, and engine room conditions.
* **Responsive Layout:** Automatically scales down seamlessly from wide laptop screens to standard smartphones.
* **Propulsion Diagnostics:** Quick-reference specs and troubleshooting matrices for major vessel components.
* **Systems Support:** Technical tracking data for electronic, pneumatic, and cooling systems.

## 📈 Continuous Updates
This project is an ongoing reference tool. Content, technical specifications, and diagnostic checklists will progressively grow and be updated as field tests continue and more machinery data is integrated.

## 🛠️ How to Save to Your Device
To make this easy to access on your phone or tablet:
1. Open the live link above using **Safari** (iPhone) or **Google Chrome** (Android).
2. Tap your browser's **Share** or **Menu** button.
3. Select **"Add to Home Screen"**.
4. This drops a clean launch icon right onto your home screen for quick access whenever you have signal.
